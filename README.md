# Tally Desk — README (Claude Code)

## What is in this folder
Tally Desk is a desktop invoicing app for freelancers and small companies of up to ten people (a made-up app for practice). Source: project/Approved — brief v1.0.

| Folder | What is in it |
|---|---|
| project/ | Project files from the research phase: README v1.3, state v1.4, brief, My goal, Instructions template |
| research/ | Research files: Desk Research, Competitive Analysis, Interview Questions, Problem Statement, Persona, Dashboard, Solution, and the demo app (source of K11–K20) |
| wireframes/ | Flows v1.0, Wireframes v1.0 and the wireframe screens exported as HTML |
| app/ | The clickable prototype (code only) |

CLAUDE.md in this folder holds the project instructions that every Claude Code chat reads first.

## Two kinds of files
Files from two tools are kept apart by their names:
- **Claude (chat) files:** `Approved — Name vN.md` (and `Instructions — Template v1.md`, `Tally Desk Demo App v1.html`). Version is in the file name. These are never changed here.
- **Claude Code files:** a plain name without "Approved —" and without a version, e.g. `README.md`, `state.md`. The version is in the header, and the header says "Made with: Claude Code".

## Rules
- Research and code never share a folder. All code stays in app/.
- Every folder has its own README.md and state.md.
- IDs (K, RQ, H) are kept as defined in project/Approved — brief v1.0 and project/Approved — README v1.3.
